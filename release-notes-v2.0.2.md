# Worst Luck Possible 2.0.2

## English

- Every successful fishing catch now gives exactly one pair of leather boots by default.
- The original fishing loot table, Luck of the Sea and player luck no longer affect the caught item while this mode is active.
- `/worstluck fishing vanilla` temporarily restores vanilla fishing for the current world/server session.
- `/worstluck fishing boots` restores forced leather boots immediately.
- `/worstluck fishing` reports the current mode.
- Commands require game-master/operator permission.
- The temporary override is not saved: forced boots return when a singleplayer world is reopened or the dedicated server is restarted.
- Fabric API is still not required.

## Русский

- Каждый успешный улов теперь по умолчанию гарантированно даёт одну пару кожаных ботинок.
- Пока этот режим включён, таблица рыболовного лута, «Морская удача» и удача игрока не влияют на пойманный предмет.
- `/worstluck fishing vanilla` временно возвращает ванильную рыбалку для текущей сессии мира или сервера.
- `/worstluck fishing boots` немедленно снова включает гарантированные кожаные ботинки.
- `/worstluck fishing` показывает текущий режим.
- Для команд требуются права оператора или ведущего игры.
- Временная настройка не сохраняется: ботинки снова включаются после повторного открытия одиночного мира или перезапуска выделенного сервера.
- Fabric API по-прежнему не требуется.

## Requirements / Требования

- Minecraft **1.21.11**
- Fabric Loader **0.19.5** or newer / или новее
- Java **21**

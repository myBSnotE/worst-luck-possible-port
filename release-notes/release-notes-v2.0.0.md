# Worst Luck Possible 2.0.0

The first release of the unofficial **Worst Luck Possible** port for **Minecraft 1.21.11 Fabric**.

Первый релиз неофициального порта **Worst Luck Possible** для **Minecraft 1.21.11 Fabric**.

## Requirements / Требования

- Minecraft **1.21.11**
- Fabric Loader **0.19.5** or newer / или новее
- Java **21**
- Fabric API is not required / Fabric API не требуется

## Highlights / Основные особенности

- Worst-case loot rolls and hostile mob behavior / Худшие результаты лута и усиленное поведение враждебных мобов
- Multiplayer support with nearest-player-aware spawning and despawning / Поддержка мультиплеера с учётом ближайшего игрока при спавне и деспавне
- Frequent storms and lightning / Частые грозы и молнии
- Guaranteed phantom attacks under vanilla-compatible conditions / Гарантированные атаки фантомов при выполнении ванильных условий
- Dedicated-server startup smoke-tested in GitHub Actions / Запуск выделенного сервера проверен в GitHub Actions

Download `worst-luck-possible-2.0.0.jar` from the assets below and place it into the `mods` directory.

Скачайте `worst-luck-possible-2.0.0.jar` из списка файлов ниже и поместите его в папку `mods`.

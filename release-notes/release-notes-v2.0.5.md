# Worst Luck Possible 2.0.5

## English

- Added `/worstluck lightning reduced`: each ticking chunk now has a **5% lightning-attempt chance per tick**, reducing the original rate by 20× on average.
- Added `/worstluck lightning full` to restore an attempt in every ticking chunk every tick.
- Added `/worstluck lightning` to show the current mode.
- The override is temporary and resets to full intensity when the world is reopened or the dedicated server restarts.
- Commands require game-master/operator permission.

## Русский

- Добавлена команда `/worstluck lightning reduced`: теперь каждый тикающий чанк имеет **5%-й шанс попытки удара молнии каждый тик**, что в среднем снижает исходную частоту в 20 раз.
- `/worstluck lightning full` возвращает попытку удара в каждом тикающем чанке каждый тик.
- `/worstluck lightning` показывает текущий режим.
- Настройка временная и сбрасывается на полную интенсивность после повторного открытия мира или перезапуска выделенного сервера.
- Для команд требуются права оператора или ведущего игры.

## Requirements / Требования

- Minecraft **1.21.11**
- Fabric Loader **0.19.5** or newer / или новее
- Java **21**

# Конфигурация

## Требования и способы открытия

Worst Luck Possible использует Fabric API для регистрации клавиши, событий жизненного цикла и защищённой синхронизации конфигурации между клиентом и сервером. [Mod Menu](https://modrinth.com/mod/modmenu) необязателен.

Экран настроек открывается двумя способами:

1. Выберите **Worst Luck Possible → Настроить** в Mod Menu.
2. Нажмите клавишу **Открыть настройки Worst Luck Possible** — по умолчанию `L`. Её можно переназначить в управлении.

У каждого элемента есть всплывающая подсказка. Она объясняет выбранное значение и его последствия, а не просто повторяет название. Включены русский и английский переводы.

Экран разделён на страницы **«Основные»** и **«Бой и взрывы»**. Переключение страниц ничего не сохраняет досрочно: кнопка **«Сохранить»** отправляет конфигурацию целиком.

## Профили

| Профиль | Поведение |
| --- | --- |
| Максимальная неудача | Применяет худшее управляемое модом значение ко всем настраиваемым игровым механикам. |
| Ваниль | Отключает все настраиваемые вмешательства в игровой процесс. |
| Пользовательский | Показывается автоматически, если отдельные значения больше не совпадают ни с одним полным профилем. |

Профили намеренно не изменяют «Ответственный режим»: он управляет правами доступа, а не игровым процессом.

## Настройки по умолчанию и настройки мира

Используются два независимых уровня конфигурации.

### Параметры новых миров

Файл `config/worst-luck-possible.json` содержит параметры для миров, у которых ещё нет собственной конфигурации. Экран, открытый вне мира, меняет этот файл.

Изменение глобальных параметров не переписывает существующие миры.

### Конфигурация конкретного мира

При первом запуске мира с этой версией текущие параметры копируются в:

`<папка мира>/worst-luck-possible.json`

После этого главным источником становится файл мира. Экран, открытый во время игры, показывает серверную конфигурацию, а не локальные значения клиента.

Сервер проверяет каждое изменение, нормализует неправильные проценты, сохраняет файл через временную копию и рассылает принятую конфигурацию подключённым игрокам.

## Права доступа

- На выделенном сервере менять параметры могут только игроки, прошедшие ванильную проверку прав гейм-мастера/оператора.
- В обычном одиночном мире владелец может менять параметры даже без включённых команд.
- Остальные клиенты видят экран только для чтения.
- Ручное изменение JSON владельцем файлов при выключенном сервере находится вне игровой модели прав и технически не может быть запрещено модом.

## Ответственный режим

Ответственный режим предназначен для честных миров-испытаний.

1. Включите его в глобальных параметрах перед созданием или первым запуском мира.
2. Мир копирует игровые настройки вместе с флагом ответственного режима.
3. Владелец одиночного мира больше не может менять настройки без прав оператора.
4. Включение команд/читов или получение прав гейм-мастера снова разрешает изменение.
5. Отключение самого ответственного режима требует тех же прав и отдельного подтверждения.

Изменение глобального файла не разблокирует уже существующий ответственный мир.

## Доступные настройки

### Частота гроз

| Значение | Поведение |
| --- | --- |
| Максимальная | Когда погода ясная, таймеры дождя и грозы ограничиваются 12 000 тиками — десятью минутами. |
| Ванильная | Таймеры погоды Minecraft не изменяются. |

### Цели молний

| Значение | Поведение |
| --- | --- |
| Прогруженная область | Успешная попытка использует ванильную точку поверхности в тикающем чанке. |
| Игроки и мирные мобы | Сначала выбирается находящийся под дождём игрок, затем мирный моб. Нет цели — нет молнии. |
| Игроки, мирные мобы и горючие блоки | После сущностей проверяются открытые дождю точки поверхности с горючим блоком. Нет цели — нет молнии. |
| Ванилла | Миксин не отменяет исходный метод `tickThunder`, поэтому частота, цель и лошадь-ловушка полностью ванильные. |

### Частота попыток молнии

Ползунок задаёт вероятность 1–100% для каждой управляемой модом возможности удара. `100%` соответствует максимальной интенсивности прежних версий. В ванильном режиме целей этот параметр не используется.

### Рыбалка

| Значение | Начальное ожидание | Лут |
| --- | --- | --- |
| Ванильная | Ванильный бросок 100–600 тиков | Ванильная таблица |
| Плохая | 600 тиков | Одна полностью сломанная пара кожаных ботинок |
| Долгая ванильная | 600 тиков | Ванильная таблица |

Дождь, доступ к небу, «Приманка» и последующие стадии рыбалки остаются ванильными во всех режимах.

### Умное горение

| Значение | Усиленное распространение | Старение и топливо | Возгорание от лавы |
| --- | --- | --- | --- |
| Выкл. | Ванильное | Ванильное | Ванильное |
| Вечное | До восьми дополнительных ванильно допустимых очагов | Огонь рядом с топливом удерживается на возрасте 0; случайное уничтожение топлива переносится на момент тушения | До восьми дополнительных очагов |
| Ускоренное | Принудительный проход по прямым соседям как в 2.3.1, затем допустимые воздушные точки; всего до восьми установок | Ванильное старение и расход топлива | До восьми дополнительных очагов |

Все режимы учитывают правило мира Minecraft 1.21.11 `fire_spread_radius_around_player` (`-1` разрешает распространение огня везде). В режимах «Вечное» и «Ускоренное» новой воздушной позиции огня дополнительно требуется горючий блок прямо снизу; исходные ванильные установки огня и лавы во время усиленного тика проходят ту же проверку. «Выкл.» сохраняет ванильные правила размещения.

### Разброс снарядов игрока

| Значение | Поведение |
| --- | --- |
| Ванильный | Сохраняет случайную ванильную погрешность снарядов. |
| Худший разброс | Выбирает меняющуюся точку на границе того же покомпонентного диапазона погрешности, не изменяя скорость снаряда. |

### Наведение вражеских снарядов

| Значение | Поведение |
| --- | --- |
| Ванильное | Сохраняет обычный случайный разброс враждебного стрелка. |
| С упреждением | Использует только ванильный диапазон погрешности, чтобы приблизить траекторию к предсказанной позиции игрока. Если точное упреждение выходит за диапазон, выбирается ближайшее разрешённое направление. |

### Критический урон снарядов

| Значение | Поведение |
| --- | --- |
| Ванильный | Сохраняет ванильную случайную критическую прибавку. |
| Худший исход | Минимизирует прибавку постоянных снарядов игрока и максимизирует её у снарядов враждебных мобов. |

### Взрывы

| Значение | Поведение |
| --- | --- |
| Ванильные | Не изменяет случайную силу лучей, броски возгорания и зависящие от взрыва броски выпадения блоков. |
| Максимально разрушительные | Использует максимальную ванильно случайную силу лучей, гарантирует допустимые броски огня у уже огненных взрывов и отменяет зависящее от взрыва выпадение, когда ванилла допускает потерю. |

## Удалённые команды

Команды `/worstluck fishing ...` и `/worstluck lightning ...` удалены. Временные значения сессии заменены сохраняемой конфигурацией.

Диагностические команды остаются в `/worstluck debug ...` и требуют прав оператора.

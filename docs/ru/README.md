# Документация Worst Luck Possible

Здесь подробно описано поведение порта для Minecraft 1.21.11. Каждый раздел отдельно объясняет:

- **Ванилла** — исходное правило или случайный бросок Minecraft.
- **Мод** — какое значение или решение изменяет Worst Luck Possible.
- **Результат** — что в итоге видит игрок.

Основной принцип приведён в разделе [Границы вмешательства в случайность](randomness-boundaries.md): мод ухудшает случайные значения, вычисляемые во время игры, но не переписывает результаты, уже определённые сидом мира или таблицы.

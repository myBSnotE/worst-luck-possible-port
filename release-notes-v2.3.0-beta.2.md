## Worst Luck Possible 2.3.0-beta.2

Исправление чрезмерного разброса снарядов игрока.

В предыдущих версиях поверх ванильной неточности добавлялся независимый случайный поворот до ±180° по yaw и pitch. Такой исход невозможен в ванилле и особенно заметен на жемчуге Края.

Теперь мод использует реальную формулу Minecraft 1.21.11: к каждому компоненту нормализованного направления может добавляться не более `0.0172275 × uncertainty`. Из восьми предельных ванильных комбинаций выбирается та, которая даёт наибольшее угловое отклонение от прицела; при равных вариантах сторона выбирается случайно.

Для обычного значения `uncertainty = 1` абсолютная теоретическая граница составляет менее 1,71°, а для направления вдоль одной из осей фактический максимум — около 1,42°. Скорость и индивидуальный коэффициент неточности конкретного снаряда сохраняются.

Все остальные механики beta.1 оставлены без изменений.

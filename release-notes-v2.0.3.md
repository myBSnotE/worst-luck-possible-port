# Worst Luck Possible 2.0.3

## English

- Leather boots caught while worst-luck fishing is active now have **zero remaining durability** instead of a full durability bar.
- The temporary vanilla-fishing commands introduced in v2.0.2 are unchanged.

## Русский

- Кожаные ботинки, пойманные при включённой худшей рыбалке, теперь имеют **нулевую оставшуюся прочность**, а не полную шкалу.
- Временные команды ванильной рыбалки, добавленные в v2.0.2, не изменились.

## Requirements / Требования

- Minecraft **1.21.11**
- Fabric Loader **0.19.5** or newer / или новее
- Java **21**
